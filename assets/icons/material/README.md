- `lightbulb.svg`: https://github.com/google/material-design-icons/tree/master/symbols/web/lightbulb
- `desktop_windows.svg`: https://github.com/google/material-design-icons/tree/master/symbols/web/desktop_windows
- `biotech.svg` (microscope): https://github.com/google/material-design-icons/tree/master/symbols/web/biotech

Downloaded 2026-11-27 from `symbols/web/<name>/materialsymbolsoutlined/<name>_24px.svg`.
